# ⚽ Football League & Knockout Manager

A dynamic football points calculator with automatic standings, league fixtures, and a knockout bracket. Built with React, Tailwind CSS, and Framer Motion.

## Features
- 🏟️ **League mode** – any number of teams, custom match legs (round‑robin)
- 🏆 **Knockout bracket** – top 2/4/8 qualify, visual bracket with editable scores
- 🥇 **Auto‑updating points table** – points, goal difference, goals for
- 🔥 **Finalist highlighting** – green glow + "🏆 Finalist" badges
- 💾 **Persistent data** – everything saved to localStorage
- 🎨 **Football‑themed UI** – stadium background, glassmorphism, animations

## Tech Stack
- React (Vite)
- Tailwind CSS
- Framer Motion
- localStorage for state persistence
